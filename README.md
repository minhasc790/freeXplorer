## 🔧 Troubleshooting Common Issues

**The drive does not appear in the list.** Unplug the enclosure, wait five seconds, and plug it back into a different USB port. Avoid USB hubs where possible, and click refresh afterward. If you are using a SATA adapter, confirm the power cable is connected as well as the data cable.

**Windows asks to format the drive.** Decline that prompt. Windows does not understand the console file system, and formatting would erase everything. Close the prompt and use freeXplorer instead.

**The application closes immediately after opening.** Right-click the file and choose the option to run it as administrator. Also check that your antivirus is not holding the downloaded file in quarantine; if it is, restore the file and add an exception.

**Copying is very slow.** Large folders with thousands of small files take time. Close other programs that use the drive, and connect through a USB 3.0 port if your enclosure supports it.

**Files copied to the drive do not show up on the console.** Make sure the file names and folder paths match exactly what the console expects. Even a single extra space can cause a file to be ignored.
